# Offline catalog

Natural Earth public-domain admin0/admin1 10m bounds.
https://www.naturalearthdata.com/about/terms-of-use/
https://github.com/nvkelso/natural-earth-vector/tree/master/geojson

Rectangular bounds include surrounding water/neighbors; no polygon clipping. Administrative labels reflect the dataset, not guaranteed current official subdivisions. Country names localized with Babel nb; regional names retained. Antarctica excluded; latitude clamped +/-85. Dateline-spanning full areas require smaller selections. Existing 30000 estimated tile budget per style determines default detail. No fabricated byte sizes or offline routing/search.
